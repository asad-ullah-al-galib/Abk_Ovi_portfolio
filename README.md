# Personal Website

A Next.js portfolio site inspired by `shuvo.dev`.

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- `next-themes`

## Run locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Production

Build the app:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

## Project structure

- `app/` App Router entrypoints and global styles
- `components/portfolio/` homepage composition
- `components/ui/` shared UI primitives
- `lib/` utilities

## Notes

- This repo is now Next-only. The old static HTML/CSS/JS site files have been removed.
- If `npm` is not available on your machine, install Node.js first.
